## Reproducibility

Every figure and table in the manuscript is generated by the pipeline in the project
repository (`R/run_all.R`, steps 01–08) from the raw data
(`ssi2012_cleaned.dta`). No estimate or sample size is hardcoded; the
`VERIFICATION_REPORT.md` in the repository documents the full pre-resubmission audit
(pipeline rerun, appendix and main-text number checks, document integrity, blinding).

## Compiling the manuscript

```
latexmk -pdf manuscript_R1.tex
```

Requires a standard LaTeX distribution with `booktabs`, `tabularx`, `natbib`,
and `tcolorbox` (response memo only).
