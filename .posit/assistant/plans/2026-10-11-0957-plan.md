## Phase 1 — Rebuild the pipeline (`R/`)
Create a numbered pipeline; each artifact is produced by exactly one script with a unique output path:
- `R/01_dataproc.R` — consolidated data cleaning (from `dataproc.R`): robust data-path resolution with a clear error if missing; fix `percclass` NA edge; remove stale `do/dataproc.do` comment; replace deprecated `case_match()`.
- `R/02_samples.R` — **compute** (never hardcode) all sample sizes and write `tables/sample_sizes.csv` for citation: flow counts (3,782 → 2,275), complete cases (2,253), primary 25+ sample, tier Ns, quadrant Ns, status-free subset (157/152/148), sensitivity N (expect 1,649), ES/CS F-tests.
- `R/03_models_did.R` — baseline generalized DiD mixed model (N=457) **per Eq. 5**, pooled DiD (N=1,981), 4-tier education DiD (**new code**), 24-cell quadrant matrix; primary + full-sample versions; save `tables/*.rds`.
- `R/04_models_behavioral.R` — multinomial Stay/Conform/React with **AMEs** (IPW via WeightIt), primary + sensitivity (excl. Taste-Only).
- `R/05_ipw_balance.R` — multinomial IPW (age, female, raceeth, parented), love plot, SMDs.
- `R/06_models_appendix.R` — stepwise education-alone/class-alone (primary + full), unweighted-vs-IPW comparison (Table A.5), MDE analysis **with data-computed inputs**, full-sample descriptives counts.
- `R/07_make_figures.R` — all 9 manuscript figures, standardized ordering, no literal estimates, no hardcoded axis limits, unique filenames (primary vs full-sample clearly suffixed).
- `R/08_make_tables.R` — generate as `.tex` every currently hand-typed results table: A.2 (4-tier), A.3 (24-cell), A.5 (IPW comparison), A.6 (full descriptives), A.8 (full 24-cell). Table 1 (with Census benchmarks) and Table 2 (verdicts) remain typed but their internal counts/estimates will be programmatically verified.
- `R/run_all.R` — master script sourcing 01–08 in order; one command regenerates everything.
- Move superseded scripts (`analysis.qmd` pipeline duplicates, `advanced_models.R`, `sensitivity_analysis.R`, `visualization.R`, `did_visualization.R`, `generate_did_barplots.R`, `generate_figure_baseline_influence.R`, `replication_models.R`, `appendix_robustness.R`, `generate_all_updated_assets.R`, old stepwise scripts) to `R/legacy/` with a README noting they are superseded.
